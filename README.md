## 📌 关于本仓库

这是我的个人研究仓库，聚焦**自动驾驶在恶劣天气（雨、雾、雪、夜间、强光）下的VLA方法**。

- 🎓 **目标**：硕士期间完成1项专利 + 1篇EI/SCI论文
- 🗓️ **维护周期**：2026.10 - 2029.06
- 🛠️ **主要内容**：论文精读笔记、代码复现、工具脚本、学习笔记
