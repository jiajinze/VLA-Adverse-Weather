# JarvisIR (CVPR 2025)

**全名**: JarvisIR: Elevating Autonomous Driving Perception with Intelligent Image Restoration

**作者/机构**: 港中文 + 香港科技大学(广州) + 腾讯 + 厦大 + 字节Pico + 华为诺亚方舟

**链接**:
- arXiv: https://arxiv.org/abs/2504.04158
- CVPR 2025

## 核心一句话

> 用一个VLM（Llava-Llama3-8B）当"调度员"，自动决定"用什么模型、按什么顺序"修复恶劣天气图片。

## 问题

现有方法三大缺陷：
1. **单一任务模型**：如"去雨专用"，换雾天就失效
2. **All-in-One模型**：一个模型搞定所有，但合成训练→真实场景泛化差
3. **多专家组合**：效果好，但任务**顺序敏感**——先去雨还是先去雾？顺序错了崩

## 方案

```
输入图片 → VLM (Llava-Llama3) 理解 → 自动选模型+定顺序 → 调用专家模型 → 输出干净图
```

关键技术：
1. **VLM作为Controller**：看图决策
2. **两阶段训练**：
   - 阶段1: SFT（监督微调）— 用合成数据训
   - 阶段2: MRRHF（人反馈对齐）— 用真实数据无监督微调
3. **CleanBench数据集**：150K合成+80K真实指令数据

## 实验结果

| 场景 | MUSIQ分数 | 提升 |
|------|----------|------|
| Night | 67.25 | +42.2% vs AutoDIR |
| Rain | 70.38 | - |
| Fog | 74.22 | - |
| Snow | 73.87 | - |

决策质量：Top 4.8%策略（超越人类专家18.6%）
