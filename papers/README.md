## 笔记模板

每篇论文笔记包含：
- **基本信息**：作者、会议/期刊、链接
- **核心一句话**：用大白话讲清楚
- **问题**：现有方法的缺陷
- **方案**：作者怎么解决
- **创新点**：和现有方法比新在哪
- **实验结果**：核心数字
- **复现可行性**：硬件/代码/数据
- **我的思考**：启发 + 潜在创新点
